# Фаза 00 — Фундамент

**Статус:** готово. **Цель:** бот отвечает, авторизация по `telegram_user_id` работает, роли разграничены.

## Что построено

- Laravel 13 + Docker Compose (`app`, `queue`, `db`, `redis`) — см. [[Стек и инфраструктура]].
- Схема: `users`, `masters` + справочники (`appliance_types`, `brands`, `geo_zones`, `time_slots`) с pivot-таблицами связей мастера.
- `TelegramClient`, `VerifyTelegramWebhookSecret` (заголовок `X-Telegram-Bot-Api-Secret-Token`), `UpdateHandler` как единая точка входа что для вебхука, что для `telegram:poll` (локальная разработка без публичного HTTPS — ТЗ п.94).
- `BotMenu` — клавиатуры по ролям, "Пользователи" только у SUPERADMIN.
- `OwnerSeeder` — выдаёт SUPERADMIN тому, чей `telegram_user_id` в `.env` (`TELEGRAM_OWNER_ID`).

## Пойманные баги (не в коде из ТЗ — в собственной обвязке)

- `docker-compose` `env_file` ломал изоляцию тестового окружения — см. [[Решения#PHPUnit env vs $_SERVER]].
- Cyrillic-путь проекта ломает BuildKit — см. [[Стек и инфраструктура#Известный готча Cyrillic-путь + BuildKit]].
